# RB Videofire 0.1 — Checklist de Validação e Plano de Merge

Repositório: `nandoribersbr/rbvideofire2026`

Branch de desenvolvimento: `rebuild/rb-videofire-0.1`

Branch de segurança: `backup/pre-rb-videofire-0.1-2026-10-01`

Branch de produção: `main`

Versão alvo: `0.1.0`

## Regra de liberação

O merge para `main` só pode ocorrer com todos os testes críticos aprovados. Qualquer falha P0 ou P1 bloqueia o merge.

## Gate A — Build

- [ ] Workspace Rust compila sem erro
- [ ] Frontend compila sem erro
- [ ] Tauri compila em development
- [ ] Tauri compila em release
- [ ] Build Windows x64 é gerado
- [ ] FFmpeg e FFprobe são encontrados localmente
- [ ] Assets, ícones e licenças entram no pacote

## Gate B — Inicialização offline

- [ ] Instala em Windows 10 x64
- [ ] Abre sem internet
- [ ] Não exige login
- [ ] Não apresenta tela branca ou erro fatal
- [ ] Menus e janela principal funcionam
- [ ] Fecha e reabre corretamente

## Gate C — Projetos `.rbvf`

- [ ] Criar projeto
- [ ] Salvar com Ctrl+S
- [ ] Salvar Como
- [ ] Arquivo `.rbvf` válido é criado
- [ ] Reabrir preserva tracks, clips, textos, volume, resolução e FPS
- [ ] Projeto corrompido é rejeitado sem crash
- [ ] Migração de versão do formato não destrói o original

## Gate D — Importação de mídia

Testar: MP4, MOV compatível, MP3, WAV, PNG e JPG.

- [ ] FFprobe lê metadata corretamente
- [ ] Duração, resolução e FPS corretos
- [ ] Thumbnail gerado
- [ ] Waveform gerado quando aplicável
- [ ] Arquivo inválido não fecha o programa

## Gate E — Timeline

- [ ] Arrastar mídia para timeline
- [ ] Mover clip
- [ ] Mover entre tracks
- [ ] Trim inicial e final
- [ ] Split
- [ ] Delete
- [ ] Ripple delete
- [ ] Copy/Paste
- [ ] Duplicate
- [ ] Snapping
- [ ] Zoom e scroll
- [ ] Lock de faixa
- [ ] Mute e ocultar vídeo

## Gate F — Undo/Redo

Validar Move, Trim, Split, Delete, Add Text e Change Volume.

- [ ] Ctrl+Z restaura o estado anterior
- [ ] Ctrl+Y reaplica a ação
- [ ] Sequência de 10 operações, 10 undos e 10 redos mantém consistência

## Gate G — Preview

- [ ] Play/Pause
- [ ] Scrubbing
- [ ] Clique na régua
- [ ] Frame anterior/seguinte
- [ ] Cortes, textos e transformações aparecem
- [ ] Áudio permanece sincronizado
- [ ] Qualidades 1/4, 1/2 e Full funcionam

## Gate H — Áudio

- [ ] Áudio de vídeo, WAV e MP3 reproduz
- [ ] Volume por clip funciona
- [ ] Mute funciona
- [ ] Waveform aparece
- [ ] Áudio acompanha cortes e playhead

## Gate I — Texto

- [ ] Criar e editar texto
- [ ] Alterar fonte, tamanho, posição, escala, duração e opacidade
- [ ] Salvar e reabrir preserva o texto

## Gate J — Autosave e recuperação

- [ ] Autosave é criado após alterações
- [ ] Autosave não bloqueia a interface
- [ ] Crash simulado é detectado
- [ ] Recuperação é oferecida
- [ ] Projeto original não é sobrescrito silenciosamente

## Gate K — Mídia ausente

- [ ] Projeto abre com mídia movida
- [ ] Clip e posição são preservados
- [ ] Mídia é marcada como ausente
- [ ] Relink/localizar arquivo funciona

## Gate L — Exportação

Caso obrigatório: 1920x1080, 30 fps, H.264, AAC, MP4.

Projeto deve conter dois vídeos, cortes, áudio e texto.

- [ ] Exportação inicia
- [ ] Progresso é exibido
- [ ] Aplicativo permanece responsivo
- [ ] Arquivo final é criado
- [ ] MP4 abre em player comum
- [ ] Duração, vídeo, áudio e texto estão corretos

## Gate M — CPU fallback

- [ ] Ausência/falha de encoder por hardware é detectada
- [ ] Fallback para CPU/libx264 ocorre
- [ ] Exportação termina com sucesso

## Gate N — Cancelamento da exportação

- [ ] Cancelar encerra FFmpeg de forma controlada
- [ ] Aplicativo continua aberto
- [ ] Estado vira `cancelled`
- [ ] Arquivo parcial é tratado
- [ ] Nova exportação pode ser iniciada

## Gate O — Erros de ambiente

- [ ] Disco sem espaço gera erro compreensível
- [ ] Permissão negada não encerra o programa
- [ ] Caminhos com espaços, acentos e Unicode funcionam

## Gate P — Instalador

Artefato esperado: `RB-Videofire-Setup-x64.exe`

- [ ] Instala em Windows 10 x64
- [ ] Cria atalhos
- [ ] Inclui FFmpeg e assets
- [ ] Registra desinstalador
- [ ] Registra associação `.rbvf`
- [ ] Duplo clique em `.rbvf` abre o aplicativo

## Gate Q — Desinstalação

- [ ] Remove executável, resources, atalhos e associação `.rbvf`
- [ ] Não apaga projetos do usuário

## Gate R — Botões mortos

- [ ] Todo controle visível funciona ou está explicitamente desabilitado
- [ ] Zero botões aparentemente ativos sem ação

## Gate S — Estabilidade

Sessão mínima de 60 minutos com importação, cortes, preview, texto, undo/redo, save e exportação.

- [ ] Nenhum crash
- [ ] Nenhuma perda de projeto
- [ ] Memória não cresce indefinidamente
- [ ] Interface continua responsiva

## Gate T — Teste ponta a ponta

Fluxo obrigatório:

`instalar → desconectar internet → abrir → criar projeto 1080p30 → importar dois vídeos → importar música → editar timeline → cortar → ajustar áudio → adicionar título → salvar → fechar → reabrir → continuar edição → exportar MP4 → assistir resultado`

- [ ] Fluxo completo concluído sem falha crítica

## Classificação de falhas

### P0 — bloqueador

Exemplos: aplicativo não abre, projeto corrompe, save falha, exportação falha, instalador falha, timeline perde clips.

Resultado: merge proibido.

### P1 — crítico

Exemplos: preview inconsistente, undo falha, áudio dessincroniza, recuperação falha.

Resultado: merge proibido.

### P2 — importante

Problemas não destrutivos que podem, excepcionalmente, entrar no backlog.

### P3 — cosmético

Espaçamento, alinhamento, tooltip ou detalhe visual.

## Freeze e release candidate

Quando todos os gates críticos estiverem verdes:

1. Criar commit `chore: freeze RB Videofire 0.1 release candidate`.
2. Bloquear novas features e aceitar apenas correções.
3. Criar tag `v0.1.0-rc.1`.
4. Gerar `RB-Videofire-Setup-x64-0.1.0-rc1.exe`.
5. Executar novamente o teste ponta a ponta usando exatamente esse instalador.
6. Se houver bug, corrigir e criar `rc.2`, repetindo o ciclo.

## Plano de merge

1. Manter intacta `backup/pre-rb-videofire-0.1-2026-10-01`.
2. Garantir `P0 = 0`, `P1 = 0`, gates críticos = 100% PASS e E2E = PASS.
3. Abrir PR `rebuild/rb-videofire-0.1 → main`.
4. Título sugerido: `release: replace legacy RB Videofire with RB Videofire 0.1`.
5. Conferir CI, relatório de validação, README, licenças, remoção de legado e número de versão.
6. Preferir squash merge quando houver commits experimentais.
7. Mensagem final sugerida: `release: RB Videofire 0.1.0`.
8. Após merge, rebuild a partir de `main` e repetir smoke test.
9. Criar tag final `v0.1.0` apontando exatamente para o commit aprovado.
10. Publicar release somente depois da verificação pós-merge.

## Rollback

Se surgir problema grave após o merge, usar a branch `backup/pre-rb-videofire-0.1-2026-10-01` como referência de restauração. Fazer rollback por novo commit, sem apagar histórico.

Rollback imediato se houver corrupção de projeto, perda de arquivos do usuário, instalador inutilizável, falha de inicialização em Windows 10, exportação corrompida ou crash recorrente no fluxo principal.

O merge está autorizado somente quando:

```text
Teste E2E = PASS
Instalador RC = PASS

```
